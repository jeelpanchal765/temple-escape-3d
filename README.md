# 🏃‍♂️ Temple Escape 3D - Temple Run 2 Runner

A fast-paced 3D endless runner game built with **HTML5 & Three.js (WebGL)** inspired by **Temple Run 2**.

## 🎮 Features
- **3D Ancient Canyon & Temple Ruins**: High-speed procedural 3D tracks with cliffs, torches, pillars, and atmospheric fog.
- **Gladiator Warrior Hero**: 3D muscular barbarian character with smooth organic anatomy, bald head, handlebar mustache, shoulder fur pauldron, and combat armor.
- **Chasing Demon Monster**: Cursed Demon Beast bounding close behind you when you stumble.
- **Obstacles & Hazards**: Jump over fallen tree logs and fire pits; slide under low stone arches and roots; dodge side boulders.
- **Collectibles & Power-ups**:
  - 💎 **Diamond Gold Gems**: Collect gems to fill your Demon Idol power meter.
  - 🪽 **Flame Wings**: Supersonic flight and complete invincibility.
  - 🧲 **Coin Magnet**: Attracts all nearby gems across all lanes.
  - 🛡️ **Tiki Shield**: Absorbs fatal hits.
- **Authentic Temple Run 2 HUD**: Stone-carved score plaques, real-time powerup badges, and responsive touch controls.

## 🕹️ Controls

| Action | Keyboard | Touch / Mobile |
| :--- | :--- | :--- |
| **Move Left** | `A` or `←` | Swipe Left / Tap `◀` |
| **Move Right** | `D` or `→` | Swipe Right / Tap `▶` |
| **Jump** | `W` / `↑` / `Space` | Swipe Up / Tap `▲` |
| **Slide** | `S` / `↓` | Swipe Down / Tap `▼` |
| **Activate Boost** | `E` or Click Idol | Tap Demon Idol Icon |
| **Pause / Resume**| `P` or `ESC` | Tap Pause Button |

## 🚀 Instant Deployment (Vercel)

1. Fork or push this repository to your GitHub.
2. Go to [Vercel](https://vercel.com) and click **"Add New Project"**.
3. Import your GitHub repository.
4. Click **Deploy** (No build settings required — it deploys automatically as a static site!).
